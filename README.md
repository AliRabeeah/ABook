# A Book 📖

قارئ كتب احترافي لأندرويد — يدعم EPUB وPDF، بتصميم أسود نقي (AMOLED) مع لمسة برتقالية، ووضعين ليلي/نهاري.

## الحالة الحالية: تطبيق كامل الوظائف

### ✅ منفذ بالكامل
**المكتبة والاستيراد**
- استيراد EPUB/PDF عبر منتقي الملفات + استخراج تلقائي للعنوان/المؤلف/الغلاف
- شبكة أغلفة، بحث، فرز، شريط تقدم، قائمة ضغط مطول
- تعديل الغلاف برابط خارجي (مع معاينة فورية) + استعادة الغلاف الأصلي الفعلية
- تعديل معلومات الكتاب يدويًا (عنوان/مؤلف)
- مشاركة الملف + نافذة معلومات الملف التفصيلية

**القراءة**
- قارئ EPUB (WebView + CSS ديناميكي) وقارئ PDF (PdfRenderer)
- ثلاث تأثيرات تقليب: انزلاق، تلاشي، **وقلب واقعي (Page Curl)** عبر رسم مخصص وتتبع السحب
- وضع التمرير المستمر كبديل لتقليب الصفحات
- تحديد النص + تظليل بـ4 ألوان (محفوظ بقاعدة البيانات)
- بحث داخل الكتاب (EPUB بالكامل؛ PDF محدود تقنيًا — التفاصيل أدناه)
- قراءة صوتية (Text-to-Speech) للفصول
- قاموس/ترجمة عبر نظام أندرويد (Process Text) — بدون أي مفتاح API
- قائمة جانبية: فصول + إشارات مرجعية + إعدادات سريعة
- لوحة إعدادات كاملة: خط، تباعد، هوامش، سطوع، فلتر ليلي، محاذاة، تباين عالٍ
- مناطق لمس مخصصة للتنقل + دعم أزرار مستوى الصوت
- وضع ملء الشاشة (إخفاء أشرطة النظام) + إبقاء الشاشة مضاءة (مُطبَّق فعليًا)
- تذكير أخذ استراحة بعد ساعة قراءة متواصلة
- إحصائيات قراءة (وقت القراءة الكلي لكل كتاب)
- **إعدادات مخصصة لكل كتاب على حدة** (تجاوز اختياري للإعدادات العامة)
- حفظ تلقائي لموضع القراءة

**التصميم**
- ألوان أسود نقي (AMOLED) + برتقالي، Dark/Light Mode
- انتقال بصري (Hero-like) بين المكتبة وشاشة القراءة
- أيقونة تطبيق (Adaptive Icon)

**البنية التحتية**
- Room Database كاملة (كتب، إشارات/تظليلات، جلسات قراءة)
- **مزامنة Google Drive** (appDataFolder) — يتطلب إعداد OAuth منك، التفاصيل أدناه
- GitHub Actions لبناء APK تلقائيًا (debug/release موقّع)

### ⚠️ يتطلب خطوة إعداد منك (Manual Setup)

**1) الخطوط العربية المخصصة (Cairo / Tajawal)**
لم أضمّن ملفات خط ثنائية بالمشروع. الخطوات:
1. نزّل الملفات من [Google Fonts - Cairo](https://fonts.google.com/specimen/Cairo) و[Tajawal](https://fonts.google.com/specimen/Tajawal)
2. ضع الملفات (`cairo_regular.ttf`, `cairo_bold.ttf`, `tajawal_regular.ttf`, `tajawal_bold.ttf`) داخل `app/src/main/res/font/`
3. أعد تسمية `AppFonts.kt.example` إلى `AppFonts.kt`
4. بملف `Type.kt` أضف `fontFamily = CairoFontFamily` لأي `TextStyle` تريده

بدون هذي الخطوة، التطبيق يعمل طبيعيًا بالخط الافتراضي لأندرويد (يدعم العربية جيدًا أصلًا).

**2) مزامنة Google Drive**
الكود جاهز بالكامل لكن يحتاج بيانات اعتماد OAuth خاصة بك:
1. أنشئ مشروعًا على [Google Cloud Console](https://console.cloud.google.com)
2. فعّل **Google Drive API** من مكتبة الـ APIs
3. أنشئ **OAuth Client ID** من نوع Android:
   - Package name: `com.abook.app`
   - SHA-1: نفّذ `keytool -list -v -keystore your.keystore` واستخرج SHA-1 (استخدم نفس الـ Keystore الذي تستعمله بتوقيع الـ APK عبر GitHub Actions)
4. لا حاجة لأي تعديل بالكود أو إضافة مفتاح — Google يتحقق تلقائيًا عبر SHA-1 + اسم الحزمة عند تسجيل الدخول من الجهاز

بدون هذي الخطوة، زر المزامنة سيظهر لكن تسجيل الدخول سيفشل.

### ⏳ محدودية تقنية معروفة (وليست نقصًا بالتنفيذ)
- **البحث داخل PDF**: `PdfRenderer` المدمج بأندرويد لا يوفر طبقة نص قابلة للبحث (فقط رسم صفحات كصور). دعم هذا يتطلب مكتبة إضافية مثل PDFBox-Android أو PdfiumAndroid، وهذا قرار معماري نقترح مناقشته لاحقًا نظرًا لحجم المكتبات الإضافية.
- **تظليل نص PDF**: لنفس السبب أعلاه، غير مدعوم حاليًا (فقط EPUB).
- **إعدادات الكتاب المخصصة**: تفعيل "تخصيص لهذا الكتاب" يأخذ لقطة من الإعدادات الحالية كنقطة بداية؛ أي تعديل لاحق أثناء وجود التخصيص يحدّث الإعداد العام وليس تجاوز الكتاب تلقائيًا — يحتاج إعادة الضغط على "حفظ التخصيص" لتحديث القيم (تحسين بسيط ممكن بمرحلة لاحقة).

## بناء APK محليًا
```
./gradlew assembleDebug
```
(يتطلب Android Studio أو Gradle مُثبّت + Android SDK)

## بناء APK عبر GitHub Actions
كل push على فرع `main` يشغّل workflow تلقائيًا وينتج APK كـ Artifact قابل للتحميل من تبويب Actions.

### لبناء نسخة release موقّعة:
أضف الأسرار التالية في إعدادات المستودع (Settings → Secrets and variables → Actions):
- `KEYSTORE_BASE64` — ملف الـ keystore مُرمّز بـ base64
- `KEYSTORE_PASSWORD`
- `KEY_ALIAS`
- `KEY_PASSWORD`

بدون هذي الأسرار، الـ workflow يبني نسخة debug تلقائيًا.

## ملاحظة مهمة
كُتب هذا المشروع بالكامل بدون بيئة Android SDK فعلية لاختبار البناء محليًا. الكود مكتوب بعناية ويتبع أنماط Jetpack Compose القياسية، لكن من المتوقع ظهور أخطاء تجميع بسيطة (imports، توافق إصدارات) عند أول تشغيل فعلي لـ GitHub Actions — وهذا طبيعي بمشروع بهذا الحجم. أرسل أي خطأ من سجل البناء وسنُصلحه مباشرة.
